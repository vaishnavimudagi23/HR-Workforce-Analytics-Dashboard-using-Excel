# HR Workforce Analytics Dashboard using Excel

## Project Description
Developed an interactive HR Workforce Analytics Dashboard using Microsoft Excel to analyze employee data and monitor workforce performance. The project focuses on employee demographics, department distribution, salary analysis, hiring trends, gender diversity, and employee attrition.

## Key Features
- Analyzed 1,248 employee records to understand workforce distribution.
- Evaluated employee headcount, gender diversity, and department-wise distribution.
- Analyzed salary trends across different job roles.
- Monitored hiring trends, employee age groups, and attrition patterns.
- Compared overtime hours and employee attrition.
- Created interactive KPI cards, Pivot Charts, and slicers for dynamic analysis.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Interactive Slicers
- Data Visualization

## Project Objective
To transform employee data into meaningful HR insights and support workforce planning, employee monitoring, and data-driven decision-making.
